## 📋 Overview

Whenever a game updates, class member offsets and method RVAs change. `updater.py` automatically scans your new `dump.cs` (generated via **Il2CppDumper-GUI**) and replaces all out-of-date addresses inside your C++ source code (`main.cpp`) in seconds.

- **Zero-RAM Footprint:** Streams `dump.cs` line-by-line without buffering, preventing any system crashes on 500MB+ files.
- **Auto-Backup:** Automatically creates a `main.cpp.bak` copy before modifying anything.
- **Format Preservation:** Keeps all original code comments and structure intact.

## 🛠️ Prerequisites

1. **Python 3.8+** installed on your system.
2. [**Il2CppDumper-GUI by AndnixSH**](https://github.com/AndnixSH/Il2CppDumper-GUI) *(Recommended & Up-to-date GUI tool)*.
3. The latest updated game APK.
4. Your mod's C++ source file (`main.cpp`).

## 🚀 Step-by-Step Tutorial

### Step 1: Dump the New Game Version
1. Download and open [**Il2CppDumper-GUI**](https://github.com/AndnixSH/Il2CppDumper-GUI).
2. Select your APK file (or manually choose `libil2cpp.so` and `global-metadata.dat`).
3. Click **Start / Dump** to generate the output files.
4. Locate the generated **`dump.cs`** file in the output folder.

---

### Step 2: Organize Your Folder
Place `updater.py`, `dump.cs`, and `main.cpp` together in the same directory:

```text
📁 MyModProject/
├── 📄 main.cpp        (C++ source code)
├── 📄 dump.cs         (Generated by Il2CppDumper-GUI)
└── 🐍 updater.py      (Updater script)
```

---

### Step 3: Run the Updater

Open your terminal or command prompt in that directory and run:

```bash
python updater.py
```

*If your files have custom names or different paths, pass them directly as arguments:*
```bash
python updater.py path/to/source.cpp path/to/dump.cs
```

---

### Step 4: Recompile the Mod
Open your project in **Android Studio** or recompile using NDK:

```bash
ndk-build
```

---

## ❓ Troubleshooting

| Issue | Solution |
|:---|:---|
| `[-] File not found: dump.cs` | Ensure `dump.cs` is in the same folder as `updater.py`, or type the full path when prompted. |
| `Il2CppDumper Error` | Make sure you extracted the 64-bit (`arm64-v8a`) version of `libil2cpp.so`. |
| `Permission denied` | On Linux/macOS, grant script execution permission: `chmod +x updater.py`. |
| `Need to revert changes` | Simply rename `main.cpp.bak` back to `main.cpp`. |
